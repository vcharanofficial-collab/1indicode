# indicode
ndiCode is an AI-native programming language built in India. It bridges traditional logic with machine learning, empowering developers and researchers to build high-performance AI and computational biology systems with unmatched efficiency. India’s gift to the global AI era.

## Compiler Front-End Status

As of 2026-11-03, the C++20 compiler front end is estimated at **95% complete** (weighted estimate 95.20%) toward a validated typed representation that can later feed an LLVM backend. LLVM is not downloaded, vendored, or built as part of this project. The current implementation includes an owning source manager with indexed line/column mapping, versioned grammar v1.0.0, typed token payloads and preserved trivia, an initial lexer and parser/AST, schema-versioned `ast-json` and verified `typed-json` output with stable local symbol IDs, core name/type checks, installable CMake package, records/member access, integer ranges, nested `else if` return paths, checked numeric conversions, static/symbolic tensor shapes, list/index/for-each and named arguments, radix/separator integers, nested block comments, UTF-8 source validation, source-aware/JSON diagnostics with fix-its, and 18 CTest cases. AST/HIR JSON are serialization-only; deserialization and compatibility policies remain future work. The front end remains incomplete.
