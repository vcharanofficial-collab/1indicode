# indicode
ndiCode is an AI-native programming language built in India. It bridges traditional logic with machine learning, empowering developers and researchers to build high-performance AI and computational biology systems with unmatched efficiency. India’s gift to the global AI era.

## Compiler Front-End Status

As of 2026-11-03, the C++20 compiler front end is estimated at **69% complete** toward a validated typed representation that can later feed an LLVM backend. LLVM is not downloaded, vendored, or built as part of this project. The current implementation includes an initial lexer, parser/AST, core name/type checks, typed HIR lowering/verifier, list/index/for-each and named arguments, radix/separator integers, nested block comments, UTF-8 string validation, source-aware/JSON diagnostics, CLI, and tests. The front end remains incomplete.

See [the front-end project](1.Indicode_Complete_frent_end/README.md), [detailed progress report](1.Indicode_Complete_frent_end/docs/PROGRESS.md), [beginner roadmap](1.Indicode_Complete_frent_end/docs/ROADMAP_BEGINNER.md), and [strict community rules](1.Indicode_Complete_frent_end/docs/COMMUNITY_RULES.md) for the calculation, scope, limitations, and contribution requirements.
